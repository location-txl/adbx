# browse 实现说明

用户行为和快捷键见 [docs/browse.md](../docs/browse.md)。本页只记录实现边界，便于修改时快速定位。

## 模块职责

~~~
src/commands/browse/mod.rs
  ├─ app.rs    目录加载和会话状态
  ├─ model.rs  ls -l 条目解析、排序、筛选
  ├─ paths.rs  设备路径和拉取清单
  └─ tui.rs    事件循环、渲染、预览、编辑、拉取
~~~

所有设备 I/O 都通过 src/adb.rs：

- shell_list_dir：读取并解析目录列表。
- shell_mkdir：在当前目录创建单层文件夹。
- read_file：读取预览或编辑内容。
- write_file：通过无 PTY shell 写回文件。
- du_totals：拉取前统计可用大小。
- pull_with_progress：执行 adb pull 并轮询本地落盘进度。

## 会话状态

App 保存当前设备目录、目录条目、跨目录标记集合、返回历史、排序与筛选状态、状态消息和拉取统计。切换目录成功后才提交新目录状态；加载失败时保留当前目录并显示设备错误。

标记集合使用设备端绝对路径。拉取前会整理父子关系，避免同一子路径因父目录已标记而重复拉取；拉取完成后清空成功条目的标记，取消或失败条目保留以便重试。

## 路径与本地落点

入口拒绝相对设备路径，默认起点为 /sdcard。指定的本地输出目录先创建并规范化；省略 -o 时使用当前工作目录。adb pull 使用设备条目的最后一段名称，因此同名目标可能覆盖文件或合并目录，这是用户文档明确说明的行为。

## 预览与编辑

预览和编辑共用 10 MiB 读取上限。图片解码支持 PNG、JPEG、GIF、BMP 和 WebP；其他不含控制字符的 UTF-8 内容作为文本。无法识别的二进制、特殊文件和超限内容在状态区报错。

编辑器打开时保存远端字节快照。保存前重新读取并比较快照，远端变化进入覆盖确认状态。写回使用临时文件，成功后替换目标，并在适用时恢复原 Unix 权限、属主和属组；失败时保留编辑器内容和原文件。

编辑器还要满足控件的行数、字符数和显示列容量。容量校验既发生在打开时，也发生在输入、删除、粘贴和撤销/重做之后，避免 Unicode 宽字符或 Tab 导致渲染坐标溢出。

## 拉取进度与取消

新版 adb 可能不输出传输百分比。实现先用 du 估算总字节数，再每隔约 150 ms 读取本地落盘字节数计算近似进度。设备端大小未知时只显示条目状态，不显示百分比。

拉取子进程运行期间事件循环可以接收 q、Esc 和 Ctrl-C，终止当前 adb pull 并停止整批；du 统计阶段不具备同样的即时取消能力。本地半截文件由用户决定是否清理或重新拉取。

## 验证入口

普通单元测试覆盖解析、路径、排序、筛选、编辑器边界和预览格式。adb.rs 中的真实设备测试以 ignored 方式存在，运行前需要连接设备，并使用测试专用路径；不应在无设备时强行启用。
