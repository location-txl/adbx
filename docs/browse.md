# browse：浏览设备文件

在终端中浏览设备文件系统，支持跨目录标记、多选批量拉取、筛选、排序、预览和编辑文本。

## 用法

~~~text
adbx [-s <serial>] browse [path] [-o <dir>]
~~~

- path：设备端起始目录，默认 /sdcard；必须是以 / 开头的绝对路径。
- -o、--output：本地输出目录，默认当前工作目录；目录不存在时会自动创建。
- -s、--serial：指定设备 serial。

命令需要真实的交互式终端。起始目录无法读取时会直接退出，不会进入界面。

## 快速操作

~~~text
↑ / ↓          移动光标
→              进入目录
← / Backspace  返回上一级
Space          标记或取消标记
Enter          拉取所有已标记条目
q / Esc        退出
~~~

标记会跨目录保留。标记文件夹会递归拉取整个目录；同时标记父目录和子路径时，子路径只拉取一次。

## 筛选和排序

| 按键 | 行为 |
| --- | --- |
| / | 按名称即时筛选当前目录，大小写不敏感 |
| S / s | 在名称、大小、日期之间切换排序 |
| O / o | 翻转当前排序方向 |
| M / m | 在当前目录新建一个文件夹 |

筛选只作用于当前已加载目录，不会递归搜索设备。切换目录会清除筛选。目录始终排在文件前面。

新建文件夹时，名字不能为空，也不能是 /、.、.. 或包含控制字符；不能与当前目录已有条目重名。创建失败会显示设备返回的错误并留在输入状态。

## 预览和编辑

| 按键 | 行为 |
| --- | --- |
| v | 在右侧预览文本或常见图片；再次按 v 关闭 |
| e | 编辑 UTF-8 纯文本文件 |
| PageUp / PageDown | 滚动文本预览 |
| Home / End | 跳到预览首行或末行 |
| Ctrl-S | 保存编辑内容并继续留在编辑器 |

预览和编辑单次最多读取 10 MiB。图片支持 PNG、JPEG、GIF、BMP 和 WebP；二进制文件、设备特殊文件和无法识别的内容不能作为文本打开。

保存前会重新读取远端文件。如果远端内容已变化，界面会提示冲突；按 o 才覆盖，按 Esc 取消保存。编辑器中按 Esc 时，有未保存修改会先询问保存、丢弃或继续编辑。

## 拉取文件

Enter 会按顺序拉取所有已标记条目，并在状态区显示逐项结果和近似进度。单项失败不会中断其他条目。

输出路径使用设备端条目的最后一段名称：

- 本地同名文件可能被覆盖；
- 同名目录会合并；
- 不同设备目录下的同名条目可能落到同一个本地路径；
- 拉取过程中按 q、Esc 或 Ctrl-C 会取消当前传输并停止整批，未完成条目的标记保留以便重试，本地可能留下半截文件。

成功退出浏览器后会打印汇总，例如：

~~~text
✓ 拉取完成：成功 3 项、失败 0 项，输出目录 /Users/me/pull_out
~~~

## 示例

从默认目录开始：

~~~bash
adbx browse
~~~

从相册目录开始并指定输出位置：

~~~bash
adbx browse /sdcard/DCIM -o ~/pull_out
~~~

指定设备：

~~~bash
adbx -s 3GKL2NILLN browse
~~~

更多设备连接和终端问题见 [常见问题](troubleshooting.md)。
